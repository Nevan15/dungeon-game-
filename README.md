# ⚔️ Dungeon RPG - Text Adventure
Game petualangan text buatan Nevan!

## 📖 Cerita
Kamu masuk dungeon misterius. Pilih jalanmu, kumpulkan gold, bertahan hidup!

## 🎮 Cara Main
1. Masukin nama karakter
2. Pilih jalan (1, 2, 3)
3. Pilih goa (Tambang, Danau, Aneh)
4. Kumpulin Gold > 200 buat MENANG
5. Jangan sampe HP < 0 atau KALAH

## 🗺️ Fitur
- Sistem HP & Gold
- 3 Jalan berbeda (Lava, Harta, Paku)
- 3 Goa berbeda (Tambang, Danau, Pedagang Aneh)
- Toko: Beli potion pake gold
- 2 Ending: Kaya Raya / Mati
